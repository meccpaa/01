# Corporate governance in Hong Kong - framework [[QP]]

![](dc0755f22924618db442ab9f2046c139.jpeg)

- Both statutory requirements and non-statutory requirements
- Based on principles
- Non-statutory requirements - specified under the Listing Rules of the HKSE, including the Corporate Governance Code

The Listing Rules and CG Code

- CG Code - appendix to the SEHK Listing Rules
- 3 levels: Listing Rules, Code Provisions and recommended best practices
- Some CG requirements are imposed by the Listing Rules themselves - All listed companies must comply with these Rules - Incl. requirement for companies to include a CG Report in their annual report
- Listing Rules require companies to apply the Corporate Governance Code
- The CG Code contains some general principles, but also
	- Code Provisions (comply / explain), and
	- Recommended best practices (recommended to follow)
