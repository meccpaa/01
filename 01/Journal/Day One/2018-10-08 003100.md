# Corporate governance

The rules, systems and processes by which a company is directed and controlled.

Exchange’s view - the CG Code: applies to main board companies. Issuers are expected to comply with the Code provisions but may deviate from them if there is a reason for doing so.The issuer must explain any non-compliance with Code provisions in its annual report.

Recommended Best Practices are for guidance only
