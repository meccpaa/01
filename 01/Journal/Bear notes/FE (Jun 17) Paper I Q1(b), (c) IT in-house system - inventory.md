# FE (Jun 17) Paper I: Q1(b), (c) IT in-house system - inventory
#### (b) List three items that you would expect the management have put in place in order to demonstrate that the new in-house developed inventory system has been properly migrated from the old inventory system. (3 marks)

The following items should have been put in place by the management to demonstrate that the new inventory system has been properly migrated from the old system:

- **An approved system conversion plan** to ensure the inventory system was implemented as planned and scheduled.
- **A testing report** which summarised all of the bugs identified during the pilot run in West Wine Wholesales Company Limited.
- All of the bugs identified should have been fixed in the new system to ensure it worked as intended before it was rolled out to other subsidiaries.
- Program changes made to the system were documented and approved.
- Training was provided to all users on how to use the new system.
- Data maintained in the original systems were properly converted and transferred to the new inventory system.
- There is a proper segregation of duties to ensure there is proper level access by different individuals as necessary.


#### (c) Assume the new in-house developed inventory system worked properly as intended and no issue was identified from auditing the information technology general and application controls. Comment on its impact in auditing the inventory costing. (2 marks)

### Answer:
The implementation of the new in-house developed inventory system can reduce the level of substantive procedures. However, while the inventory costing is calculated based on the inventory record within the same system, it is still subject to various manual inputs such as the initial purchase price, quantity, etc. The accuracy assertion thus depends on the integrity of the manual inputs which should be validated by performing other audit procedures.
