# Example: CVP analysis
Expected sales: 10,000 units at $8 = $80,000
Variable cost:  $5 per unit
Fixed costs: $21,000

### analysis
![](Example%20CVP%20analysis/50B9BEB2-1AC4-4BCF-AC55-DA9523269E35.png)

Another way of reaching the same conclusion is to use the C/S ratio. C/S ratio = $3/$8 = 0.375 Contribution required to break even (= fixed costs) = $21,000 Breakeven sales revenue = $21,000/0.375 = $56,000.
