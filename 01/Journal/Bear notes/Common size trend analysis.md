# Common size trend analysis
Common size analysis can be used to compare or benchmark financial performance against other firms within the same industry; and to get a different picture about trends for one firm. Using this approach for each line item in the income statement (or statement of financial position) is expressed as a percentage of sales (or total assets). Common size analysis is a useful way of comparing the financial results of organisations of different size, because percentage values are more easily compared.
