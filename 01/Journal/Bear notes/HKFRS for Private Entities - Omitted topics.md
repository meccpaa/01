# HKFRS for Private Entities - Omitted topics
The HKFRS for Private Entities does not address the following topics that are covered in full HKFRS, because these topics are **not generally considered to be relevant** to private entities:
- Earnings per share 
- Interim financial reporting 
- Segment reporting 
- Classification for non-current assets (or disposal groups) as held for sale
