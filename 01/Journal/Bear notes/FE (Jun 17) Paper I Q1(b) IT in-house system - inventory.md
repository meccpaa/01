# FE (Jun 17) Paper I: Q1(b) IT in-house system - inventory
The following items should have been put in place by the management to demonstrate that the new inventory system has been properly migrated from the old system:

- An approved system conversion plan to ensure the inventory system was implemented as planned and scheduled.

- A testing report which summarised all of the bugs identified during the pilot run in West Wine Wholesales Company Limited.

- All of the bugs identified should have been fixed in the new system to ensure it worked as intended before it was rolled out to other subsidiaries.

- Program changes made to the system were documented and approved.

- Training was provided to all users on how to use the new system.

- Data maintained in the original systems were properly converted and transferred to the new inventory system.

- There is a proper segregation of duties to ensure there is proper level access by different individuals as necessary.
