# VAT payable and input credit
VAT payable = Output VAT – Input VAT

Output VAT = Sales amount x applicable VAT rate (generally 17%)

Input VAT = VAT paid on purchases

Input VAT paid on purchases of raw materials, fuels and powers such as electricity, heat and gas, low-value and non-durable equipment can be claimed and set off against the output VAT.

Starting from 1 January 2009, input VAT paid on purchase of fixed assets can be creditable to offset the output VAT.
