# FE Dec 19 Paper II Section A - 2(b) NPV IRR
**(b)**In the capital budgeting process, the management conducted a feasibility test about the two new investment projects: A and B. It was found that these are the mutually exclusive projects, and each project requires HK$30 million as the initial investment. Below are the details of Project A and Project B. 
Project A is expected to generate HK$25 million in Year 1 and HK$25 million in Year 2. Project B is expected to generate HK$5 million in Year 1 and HK$50 million in Year 2. 
**Determine the NPV and IRR of each project assuming that the discount rate is 10% for both projects; and explain with details justifications which project or projects will be invested.**
**(6 marks)**
- - - -
## answer
**Answer 2(b)**
NPV of Project A
= -30 + 25 / (1.1) ^1 + 25 / (1.1) ^2
= HK$13.3884 million
IRR of Project A is as follows:
0 = -30 + 25 / (IRR) ^1 + 25 / (IRR) ^2
IRR = 42%
NPV of Project B
= -30 + 5 / (1.1) ^1 + 50 / (1.1) ^2
= HK$15.8678 million
IRR of Project B is as follows:
0 = -30 + 5 / (IRR) ^1 + 50 / (IRR) ^2
IRR = 38%
Project B will be accepted because the net present value of Project B is higher than Project A. 

Even though the IRR of Project A is higher than B, Project A will not be considered, as the net present value method is more reliable and it is an absolute measure that represents the dollar amount of value added by undertaking the project. On the other hand, IRR is only a relative measure. 
Also, since these are the mutually exclusive projects, only one project (Project B with a higher NPV) will be accepted.
