# Exam Module C: Dec 18 - Q2(b) test count
Identify and explain which type(s) of inventory items kept by ELL that the audit team should perform a test count. Advise how to perform a test count procedure. (3 marks)
- - - -
[[test counts]]

- Raw materials, WIP, finished goods  - on each of these categories - ensure they are valued and classified properly
- Concentrate on High value items - LED chip

- 2-way, compare the physical and the management records
- - - -
## Solution
As ELL had raw materials, work-in-progress and finished goods at the year end date, the auditor should perform test counts on items belonging to each of these categories so as to ensure they are valued and classified properly.

The auditor should concentrate on the LED chips which are considered to be the high value items.

When carrying out test counts, the auditor should select items from the management’s count records and from the physical inventory and check on to the other, to confirm the accuracy of the count records. These two-way tests provide evidence for completeness and existence.
