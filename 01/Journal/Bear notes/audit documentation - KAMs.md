# audit documentation - KAMs
The audit documentation shall include the '**significant audit matters**' from which the KAMs were ~selected~, together with the auditor's ~reasons for selecting~ the KAMs.

If no KAMs are communicated, then the reasons for the auditor's determination shall be documented. Likewise if a matter determined to be a KAM is not communicated [[choosing not to include a KAM]] (eg to avoid 'tipping off' in relation to money laundering), this shall be documented.
