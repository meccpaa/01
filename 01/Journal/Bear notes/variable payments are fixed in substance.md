# variable payments are fixed in substance
Variable payments are fixed in substance if they are linked to an ~event with no genuine possibility of non-occurrence~, for example:
	- (a) Payments that are made only if an asset is proven to be capable or operating during the lease term;
	- (b) There is more than one set of payments that a lessee could make but only one of those sets if realistic.
