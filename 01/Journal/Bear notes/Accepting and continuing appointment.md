# Accepting and continuing appointment
Topic highlights

Assurance engagements should only be accepted if the firm meets the requirements of the Code of Ethics for Professional Accountants and HKSQC 1 (Clarified).

The standard requires that practitioners ensure they comply with the Code of Ethics for Professional Accountants and the Quality Control Standard (HKSQC 1 (Clarified)) with regard to the assignment.
