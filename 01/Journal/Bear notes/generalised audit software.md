# generalised audit software
Generalised audit software (package programs) allows auditors to:
(a) Perform tests on an entity's computer files and databases, such as reading and extracting data from a client's systems for further testing
(b) Select data that meets certain criteria in order to create populations and samples
(c) Perform calculations on data, facilitating audit sampling and producing documents and reports 

By automating these processes, the auditors are able to devote more resources to analysing and investigating the results and so increase their chance of detection of material misstatement.
