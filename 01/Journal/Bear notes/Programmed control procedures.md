# Programmed control procedures
In the case of certain computer systems, the auditor may find that it is **not possible** or, in some cases, **not practical** to test controls by ::examining only user controls:: or ::the system's output::. The auditor may consider performing tests of controls by using computers, ~reprocessing~ transaction data or, in unusual situations, examining the ~coding~ of the application program.
